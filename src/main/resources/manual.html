Sport Management System — User Manual

Version 3.0.0 · Bugyani Team

1. Getting started

After installation, launch the app from the Start Menu (Windows) or Applications folder. You will be greeted by the start screen where you can either begin a new career or load a previously saved game.

Starting a new career

  1. Choose a sport from the dropdown: Football or Volleyball.
  2. Click Start new season →. A league of 16 teams is generated with randomized rosters, coaches and tactics.

Loading a saved game

If any save slots exist, pick one from the Continue a saved game combo box and click Load slot. Save files live in saves/ next to the application.

2. The main window

The left sidebar has five views:

  • Overview — headline stats, next week's fixtures, top of the table.
  • Standings — full league table. Columns switch between GF/GA/GD (football) and SF/SA/SD (volleyball).
  • Fixtures — every game week, collapsible, with played scores highlighted.
  • Teams — browse every club, see squad, change tactics.
  • Match Day — simulate the current week and watch the event feed live.

3. Running a season

A season consists of a double round-robin: every team plays every other team twice, home and away. Each week the app runs training, recovers fatigue, plays all scheduled matches, applies any new injuries and then updates the standings.

Tip: You can change a team's tactic from the Teams view at any point between matches. Tactics affect both match outcomes and how fatigued your players get.

Tactics

  • Balanced — neutral choice, moderate fatigue.
  • Defensive — lower scoring but less fatigue.
  • High press — more events, high fatigue cost.
  • Counter attack — reactive, rewards speed.

4. Saving and loading

From the sidebar, use 💾 Save to write the current season to one of five slots, and 📂 Load to restore any existing slot. Save files are Java serialized objects and are fully self-contained — teams, fixtures, standings and player fatigue are all preserved.

5. Sport rules in brief

Football

  • 11-a-side, roster of 18, 7 on the bench, max 3 subs per match.
  • Two halves, 45 minutes each.
  • Win = 3 pts, draw = 1 pt, loss = 0 pt.
  • Tiebreak: head-to-head → goal difference → goals for → coin toss.

Volleyball

  • 6-a-side, roster of 12, 6 on the bench, subs unlimited.
  • Best of 5 sets. Sets 1–4 first to 25, 5th set first to 15, always win by 2.
  • 3–0 / 3–1 win: winner 3 pts, loser 0. 3–2 win: winner 2 pts, loser 1.
  • Tiebreak: wins → set ratio → head-to-head → coin toss. No draws.

6. Troubleshooting

  • If the app will not start, make sure Java 17+ is installed.
  • If saves disappear, check that the app has write permission to its working directory.
  • Report bugs by opening an issue on the project's GitHub page.
